# R002 — First fixed-scene egg-to-bucket policy

> **Question** — Can the accepted Stage-1 observation/action design and simple task reward produce successful egg-to-bucket manipulation without strategy-specific shaping?
> 

<aside>
✅

**Answer:** Yes, in the fixed deterministic scene. This run proves possibility, not reliability.

</aside>

## Claim boundary

- **Directly verified:** exact run config, training history, strict bucket-success signal, absence of sophisticated rewards, and zero observed OOB terminations.
- **Recorded observation:** the trained robot caught, carried, and placed the egg; the catch and carry need mechanical refinement.
- **Not yet established:** frozen-checkpoint success probability, multi-seed reliability, robustness to changed starts, grasp quality, or sim-to-real readiness.

## Measurement note

`Episode_Termination/*` values are **not rates**. MJLab returns counts for environments reset at a simulator step, and RSL-RL averages those counts across reset-bearing steps. A final value such as 1.696 therefore means “mean successes per logged reset-bearing step,” not 169.6% success.

The success fraction above is reconstructed from the one-shot reward:

`success fraction = Episode_Reward/inside_bucket × 8 s / 25`

That conversion is exact for the captured reward definition, but it weights reset-bearing steps equally rather than every completed episode equally. Only 331/500 iterations contain these summaries because of how RSL-RL chooses episode-info keys. The export therefore cannot supply an exact all-episode success rate or binomial confidence interval.

## Interpretation

- **INFERENCE:** The policy learned the task, not merely a proxy: strict success rose while egg fall declined, and the observed playback agrees with that transition.
- **ALTERNATIVE EXPLANATION CHECKED:** No hidden grasp, reach, contact, or capture reward is present.
- **ALTERNATIVE EXPLANATION OPEN:** This seed and fixed start may be unusually favorable.
- **CONCLUSION:** R002 is proof of possibility for simple-reward, fixed-scene SpiRob manipulation.

## Decision

<aside>
🔒

**KEEP.** Freeze the reward, MDP, run bundle, and exact playback checkpoint. Do not add grasp or contact shaping merely because the catch/carry style can improve.

</aside>

## Exact next experiment

1. Identify and hash the exact checkpoint used in the successful playback.
2. Run five nominal deterministic resets only as a smoke test. If the fixed simulator repeats the same trajectory, record that fact; do not count the copies as independent statistical evidence.
3. Freeze the policy and map a 5 × 5 evaluation-only egg-position grid at x/y offsets `{−10, −5, 0, 5, 10}` mm. Write one CSV row per completed episode.
4. Record outcome, length, return, initial positions, minimum egg-to-bucket distance, maximum egg height, OOB/NaN status, and a carry-quality measure; preserve representative success and failure videos.
5. Repeat the unchanged 500-iteration training with seeds 43 and 44. Evaluate all three checkpoints on the same grid before changing the MDP.
